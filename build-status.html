ADB Recovery Command — Apple Remote Bridge
For Apple Remote Bridge (all versions). Run this from your PC when the accessibility toggle flips back off after an update. Copy-paste as one line.
adb -s 192.168.4.32:5555 shell "appops set com.sagi.appleremotebridge ACCESS_RESTRICTED_SETTINGS allow; settings put secure enabled_accessibility_services com.sagi.appleremotebridge/com.sagi.appleremotebridge.RemoteAccessibilityService:com.spocky.projengmenu/com.spocky.projengmenu.services.ProjectivyAccessibilityService; settings put secure accessibility_enabled 1"
