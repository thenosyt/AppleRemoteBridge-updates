Apple Remote Bridge - PC Fix

Option 1: One-Time Repair Command

Heads up if you're sharing this page: the person receiving it has to do the PC setup themselves (install ADB, connect their TV, paste the command). It's not automatic for them. The command is safe and skips apps they don't have, but the running and pasting is on them.
  1. On your PC, open a terminal (Command Prompt on Windows, Terminal on Mac).
  2. Make sure your TV is connected: adb devices should list it.
  3. Copy the command below (click it to select all, then Ctrl+C).
  4. Paste it into your terminal (Ctrl+V) and hit Enter.
  5. On your TV, open Apple Remote Bridge. Accessibility should show a checkmark.
Covers: Apple Remote Bridge, Projectivy Launcher, Button Mapper, Mouse Toggle for Android TV.
Safe: only touches apps you have installed. Silent for the rest.
adb shell ' for entry in \ "com.sagi.appleremotebridge|com.sagi.appleremotebridge/com.sagi.appleremotebridge.RemoteAccessibilityService" \ "com.spocky.projengmenu|com.spocky.projengmenu/com.spocky.projengmenu.services.ProjectivyAccessibilityService" \ "flar2.homebutton|flar2.homebutton/flar2.homebutton.a.ai" \ "com.fluxii.androidtv.mousetoggle|com.fluxii.androidtv.mousetoggle/com.fluxii.androidtv.mousetoggle.AccessService"; do pkg="${entry%%|*}" svc="${entry#*|}" if pm list packages 2>/dev/null | grep -q "^package:${pkg}$"; then cur="$(settings get secure enabled_accessibility_services 2>/dev/null)" case ":${cur}:" in *":${svc}:"*) ;; *) if [ "$cur" = "null" ] || [ -z "$cur" ]; then settings put secure enabled_accessibility_services "$svc" else settings put secure enabled_accessibility_services "${cur}:${svc}" fi ;; esac appops set "$pkg" ACCESS_RESTRICTED_SETTINGS allow 2>/dev/null echo "Enabled: $svc" fi done settings put secure accessibility_enabled 1 echo "Done." '

Option 2: Automatic Background Fix (Recommended)

Same deal as above: whoever uses this has to do the setup themselves (install Python, install ADB, connect their TV, run the script). It's automatic after that, but the setup is on them.
  1. Download the auto-fix script on your PC.
  2. Install Python 3 from python.org (check "Add to PATH" during install).
  3. Make sure ADB is installed and in your PATH.
  4. Connect your TV: adb connect <TV-IP>:5555 (or via USB).
  5. Run: python a11y-autofix.py
  6. Leave it running. It checks every 5 minutes and fixes accessibility automatically after updates.
To run on Windows startup: press Win+R, type shell:startup, and put a shortcut to the script there.
Run the one-time command when the accessibility toggle flips off after an app update. Or use the automatic script and never think about it again.
